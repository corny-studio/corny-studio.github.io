Projects

A static site with a verifiable security posture

This portfolio is built so there is little to attack. It is static, so there is no server-side code, login or database to compromise. A Content Security Policy allows only this site's own scripts, HSTS keeps every connection on HTTPS, and further headers block content-type sniffing, embedding in other sites, referrer leakage and unneeded browser features.

The page checks its own response headers in your browser, reports a pass or fail for each, and links to three independent scanners, so the result doesn't rest on my word. Known limits are stated openly: the styles are still inline, and the background loads one third-party library, three.js, which is locked with an integrity hash. Moving the styles into their own file is planned.
